### Интервью с аудируемой стороной
1. **Почему в config/settings.py лежат ключ-заглушка и DEBUG = True?** — Проект запускали только локально, ключ помечен комментарием «только для разработки»; настройки развёртывания в ЛР №6–8 не рассматривались.
2. **Когда в последний раз обновляли таблицу трассировки и контракт API?** — В ЛР №7. После ЛР №8 исключения оплаты и отмены в документы не добавляли: их правят вручную после кода.
3. **Почему в requirements.txt диапазоны версий, а не точные?** — Файл составили вручную в ЛР №6 и ни разу не пересобирали из pip freeze.
