# Системные тест-кейсы «Такси» (для кросс-тестирования)

Запуск: по README, затем `python manage.py loaddata demo`. Сервер: http://127.0.0.1:8000/

| ТК | Предусловие | Шаги | Ожидаемый результат |
|---|---|---|---|
| ТК-01 | demo загружена, заказов нет | `/` → «Заказать» у «Эконом» → подача 51.1 / 71.4, назначение 51.15 / 71.45, телефон +77011234567 → «Заказать» | Страница поездки: статус «Поиск», водитель с автомобилем, срок оплаты (10 минут) |
| ТК-02 | выполнен ТК-01 | `/order/` → те же данные, тот же телефон | Над формой: «У вас уже есть активная поездка» (БП-04) |
| ТК-03 | — | `/drivers/` → широта 10, долгота 10 → «Найти» | «Координаты вне зоны обслуживания» (БП-01) |
| ТК-04 | — | `/order/` → телефон 8701 | Под полем: «Введите номер в формате +77011234567» |
| ТК-05 | demo загружена | Открыть `/api/drivers/search/?lat=51.1&lon=71.4`, затем `?lat=10&lon=10` | Первый адрес: JSON-список водителей с `eta_min`; второй: ответ 400 с текстом ошибки |
