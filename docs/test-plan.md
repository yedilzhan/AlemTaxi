# План тестирования «AlemTaxi», версия 0.2 (UC-01)

## 1. Объект тестирования
Сценарий UC-01 «Заказ поездки»: шаги выбора тарифа, ввода телефона клиента, создания заказа, назначения водителя и изменения статусов. Модули `catalog`, коммит ветки `main`.

## 2. Что тестируем
- БП-01: выбор доступных и активных тарифов из базы данных.
- БП-02: расчет стоимости поездки с учетом базовой цены и километража.
- БП-03: расчет предоплаты (30% от базовой цены тарифа).
- Формат ввода номера телефона клиента и валидация полей.
- Переходы статусов заказа (`created`, `accepted`, `completed`, `cancelled`).
- Коды ответов API по контракту (200, 400, 404).
- Отображение данных на экранах Э-01 (Тарифы) и связанных интерфейсах.

## 3. Что не тестируем и почему
- Вход по SMS и интеграция с реальным платежным шлюзом — ещё не реализованы на текущей итерации ходячего скелета.
- Нагрузочное тестирование и глубокая безопасность — вне рамок учебной итерации проекта.
- Административная панель Django — является стандартным кодом фреймворка и не требует кастомного тестирования бизнес-логики.

## 4. Уровни и методы
| Уровень | Метод | Инструмент |
| :--- | :--- | :--- |
| Модульный | Чёрный ящик: классы, границы, состояния | Django TestCase |
| Модульный | Белый ящик: покрытие ветвей | coverage.py --branch |
| Интеграционный | Сверху вниз с заглушками | unittest.mock |
| Системный | Ручные тест-кейсы, кросс-тестирование | браузер, GitHub Issues |

## 5. Среда
Windows 11 / Ubuntu 24.04, Python 3.12, Django 5.2, SQLite, Chrome. Тестовые данные подгружаются через фикстуру `demo.json`.

## 6. Критерии входа
Проект успешно клонируется и запускается по инструкциям из `README.md` на чистом компьютере, все базовые тесты ЛР №7 проходят без ошибок.

## 7. Критерии окончания
- Все автоматические тесты проходят успешно, линтер `ruff` не выдает ошибок.
- Покрытие ветвей слоя бизнес-логики (`catalog/services.py`) составляет $\ge$ 90 %.
- Каждая строка таблицы трассировки проверена хотя бы одним автотестом.
- Отсутствуют открытые дефекты с приоритетом «Критическая» и «Высокая».
